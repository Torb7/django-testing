## Тестирование

Реализовал автоматизированное тестирование двух Django-проектов — YaNote и YaNews.

**Инструменты:**
- `unittest` — тестирование YaNote.
- `pytest` — тестирование YaNews.
- Фикстуры для подготовки тестовых данных и настройки тестового окружения.
- Параметризация тестов для проверки различных сценариев без дублирования кода.

**Покрытые аспекты:**
- Маршрутизация и доступность представлений для анонимных и авторизованных пользователей.
- Проверка контекста представлений, содержимого страниц и доступности форм.
- Бизнес-логика создания, редактирования и удаления объектов.
- Разграничение прав доступа и проверка принадлежности объектов пользователям.
- Валидация данных и обработка некорректных запросов.
- Проверка сортировки и ограничения количества отображаемых объектов.
